# Dictation Diary

Aqua Voice is hold-a-key dictation for the Mac that cleans up your speech as you talk, aimed squarely at people who write prompts all day.

**Read the full page:** https://aqua-voice-dev.github.io/

Buy it if you write prompts, code comments and long messages on a Mac and you are tired of your own typing speed being the bottleneck. Skip it if you are not on macOS, because the only download button on the site is the Apple one. The caveat is direction: this turns speech into text and nothing else, so if what you need is the reverse, a voice reading your text or a cloned voice for a video, Supavocal is the tool for that job, not this one.
